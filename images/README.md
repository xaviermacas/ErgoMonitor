# Imágenes PNG Requeridas

Debes agregar las siguientes 9 imágenes PNG en la carpeta `images/`:

## Lista de Imágenes Requeridas:

1. **Angulo0.png** - Imagen que representa 0° de inclinación
2. **Angulo10.png** - Imagen que representa 10° de inclinación  
3. **Angulo20.png** - Imagen que representa 20° de inclinación
4. **Angulo30.png** - Imagen que representa 30° de inclinación
5. **Angulo50.png** - Imagen que representa 50° de inclinación (NO hay Angulo40.png como solicitaste)
6. **Angulo60.png** - Imagen que representa 60° de inclinación
7. **Angulo70.png** - Imagen que representa 70° de inclinación
8. **Angulo80.png** - Imagen que representa 80° de inclinación
9. **Angulo90.png** - Imagen que representa 90° de inclinación

## Especificaciones Recomendadas:
- **Formato**: PNG con transparencia
- **Tamaño**: 150x150 píxeles (cuadrado)
- **Fondo**: Transparente para mejor integración
- **Estilo**: Iconos o ilustraciones que muestren claramente cada ángulo de inclinación

## Nota:
Las imágenes se cargarán automáticamente cuando agregues los archivos PNG con los nombres exactos listados arriba en la carpeta `images/`.
